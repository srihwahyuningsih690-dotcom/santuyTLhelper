ShrinkMe (penghasilan)

Token hanya disimpan di browser admin ini (tidak diupload ke Firebase). Ambil token: shrinkme.io → Tools → Developers API.

Hubungkan Firebase (agar data muncul di semua device)

Isi konfigurasi Firebase di bawah, lalu simpan & upload ulang file HTML ini ke hosting. Setelah terhubung, file yang disimpan admin akan terlihat di HP/laptop lain.

Langkah cepat:
1. Buka console.firebase.google.com
2. Buat project → Build → Realtime Database → Create Database → mulai mode test
3. Project settings (ikon roda gigi) → Your apps → Web → salin config
4. Tempel di bawah → Simpan config di file (tombol) → download HTML → upload ke hosting

Rules Realtime Database (test / publik baca-tulis untuk arsip sederhana):

{ "rules": { ".read": true, ".write": true } }

Untuk produksi, batasi write (misalnya hanya path tertentu). Mode test cocok untuk mulai.
